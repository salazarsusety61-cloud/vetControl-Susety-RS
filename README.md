# vetControl — Registro de Mascotas
Proyecto en C# Windows Forms para registrar mascotas de una veterinaria.

## Funcionalidades
- Agregar mascotas con nombre, especie, edad, peso, costo y sexo
- Mostrar lista de mascotas registradas
- Contador total de mascotas
- Botones: Resaltar, Limpiar y Salir

## Tecnologías
- C# / .NET Framework / Windows Forms
- Visual Studio
